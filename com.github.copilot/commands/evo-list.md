# List Experiences

Call `evo_search` with `{ "query": "", "limit": 25 }` to list stored Experiences, then present a concise grouped preview (`Team`, `Local`, `Starter`) showing each item's `type` (`Knowledge`, `Rule`, or `Fix`), `id`, `title`, `signals`, and a one-line `summary`.
