# Open Copilot Evo Canvas

Call `open_canvas` once with:

```json
{
  "canvasId": "evo-dashboard",
  "instanceId": "copilot-evo-dashboard",
  "input": {}
}
```

After success, briefly confirm that the Copilot Evo Canvas panel is open.
